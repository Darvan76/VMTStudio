# VMT-Studio 0.2.2

This maintenance release improves cancellation and responsiveness around asset
loading, material previews, connection discovery and exports, and hardens the
Windows update and portable distribution paths.

- Keep the last valid material preview and drain engine work before closing or
  reconnecting. A backend that never answers readiness no longer reports success.
- Handle special characters in update destinations, isolate concurrent downloads,
  discard cancelled preparations and keep recovery files when applying an update
  fails.
- Preserve command-line arguments through the portable launcher and serialize its
  first extraction when multiple instances start together.
- Ship verified runtime dependencies, dependency license notices and checksums.
  Debug dependencies and Windows version metadata now match the source version.
- Expand regression coverage for asynchronous UI work, IPC and VTF decoding.

## Downloads

- `vmtstudio-v0.2.2-win64.zip`: extract and run `vmtstudio.exe`.
- `VMT-Studio-v0.2.2-Portable.exe`: extracts the same payload into
  `%LOCALAPPDATA%/VMTStudio/app-v0.2.2/` and launches it.
- `SHA256SUMS`: SHA-256 hashes for both artifacts.

Windows 10/11 x64 is required. Rendering additionally needs a compatible x86
Source engine installation. Retail game DLLs and content are not bundled.
Garry's Mod and x64-only engine installations remain unsupported. Executables
are unsigned. See `THIRD_PARTY_NOTICES.md` for dependency licensing.
